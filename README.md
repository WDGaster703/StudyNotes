# 学习笔记

仓库是本人的电机方向理论基础学习笔记。包括：

- 电路理论
    - 电路理论基础
      - 主要内容：直流/交流稳态分析，三相电路分析，暂态分析，二端口网络，均匀传输线分析
      - 参考书：孙立山、陈希有等编著，电路理论基础（第四版），高等教育出版社。
    - 模拟电子技术
      - 主要内容：信息半导体器件，分立元件放大电路，反馈分析，信号运算处理电路，波形发生变换电路，直流电源
      - 参考书：清华大学童诗白、华成英主编，模拟电子技术基础（第六版），高等教育出版社。
    - 数字电子技术
      - 主要内容：逻辑代数，门电路，组合逻辑电路，时序逻辑电路，脉冲波形的产生和整形电路，AD/DA转换
      - 参考书：清华大学阎石，王红主编，数字电子技术基础（第六版），高等教育出版社。
    - 电力电子技术
      - 主要内容：电力电子器件，整流电路，逆变电路，DC-DC 变流电路，AC-AC 变流电路，PWM控制技术
      - 参考书：西安交通大学刘进军、王兆安主编，电力电子技术（第六版），机械工业出版社。
    - 高频电子电路（暂未学习）
- 控制理论
    - 经典控制理论
      - 主要内容：基于传递函数的控制理论：传递函数模型，时域分析，稳定性分析，根轨迹分析，频域分析与校正，非线性系统分析
      - 参考教材：自动控制原理（上册）. 裴润，宋申民，哈尔滨工业大学出版社。
    - 现代控制理论
      - 主要内容：基于状态空间的控制理论：状态空间模型，状态空间时域分析，能观能控性，Lyapunov 稳定性分析，状态空间综合
      - 参考教材：自动控制原理（下册）. 裴润，宋申民，哈尔滨工业大学出版社。
    - 最优控制理论
      - 主要内容：最优控制问题，变分法，庞特里亚金 Pontryagin 极小值原理，动态规划
      - 参考教材：自动控制原理（下册）. 裴润，宋申民，哈尔滨工业大学出版社。
    - 随机控制理论
      - 主要内容：随机过程，随机系统的数学模型，随机系统的分析，卡尔曼滤波
      - 参考教材：蔡尚峰编著，随机控制理论，上海交通大学出版社。
- 电机理论
    - 电磁场
      - 主要内容：矢量分析，静电场，恒定电场，静磁场，时变电磁场，准稳态电磁场
      - 参考教材：西安交通大学冯慈璋、马西奎著，工程电磁场导论，高等教育出版社。
    - 电机学
      - 主要内容：磁路，直流电机，交流电机共同问题，感应电机，同步电机
      - 参考教材：电机学（第五版），汤蕴璆编著，机械工业出版社。
    - 永磁同步电机
      - 主要内容：永磁同步电机的数学模型，SVPWM 技术，FOC 控制
      - 参考教材：现代电机控制技术（第二版），王成元, 夏加宽, 孙宜标编著，机械工业出版社。
