# 学习笔记

仓库是本人的电机方向理论基础学习笔记。包括：

- 电路理论
  - 电路原理
    - 参考教材：孙立山、陈希有等编著，电路理论基础（第四版），高等教育出版社。
    - 主要内容：
      - 电路元件与电路基本定律
      - 线性电路稳态分析：线性直流电路稳态分析，正弦交流电路稳态分析，非正弦周期交流电路稳态分析，三相电路初步，频率响应
      - 线性电路暂态分析：时域分析与复频域分析
      - 二端口网络
      - 非线性电路分析
      - 分布参数电路分析：均匀传输线
  - 模拟电子技术基础
    - 参考教材：清华大学童诗白、华成英主编，模拟电子技术基础（第六版），高等教育出版社。
    - 主要内容：
      - 信息半导体器件
      - 分立元件放大电路：单管放大电路，多级放大电路
      - 反馈分析
      - 集成元件电路：信号运算电路，波形发生变换电路
      - 直流电源
  - 数字电子技术基础
    - 参考教材：清华大学阎石，王红主编，数字电子技术基础（第六版），高等教育出版社。
    - 主要内容：
      - 数学基础：逻辑代数
      - 电路基础：门电路，脉冲波形的产生和整形电路
      - 逻辑电路设计与分析：组合逻辑电路，时序逻辑电路
      - AD / DA 转换
  - 电力电子技术
    - 参考教材：西安交通大学刘进军、王兆安主编，电力电子技术（第六版），机械工业出版社。
    - 主要内容：
      - 电力电子器件
      - 电力电子变换拓扑：整流电路，逆变电路，DC-DC 变流电路，AC-AC 变流电路
      - 电力电子变换器控制：PWM 控制技术
- 控制理论
  - 信号分析与处理
    - 参考教材：赵光宙主编，信号分析与处理（第四版），机械工业出版社。
    - 主要内容：
      - 连续信号分析：CFS，CTFT
      - 离散信号分析：DFS，DTFT，DFT，FFT
      - 信号处理基础：系统的性质与分析
      - 滤波器设计初步：模拟滤波器，数字滤波器
  - 经典控制理论
    - 参考教材：裴润，宋申民主编，自动控制原理（上册），哈尔滨工业大学出版社。
    - 主要内容：基于传递函数模型的控制理论
      - 系统建模：传递函数模型，方框图与信号流图
      - 系统分析：时域分析，稳定性分析，根轨迹分析，频域分析
      - 系统综合：频域校正
      - 非线性系统分析
  - 现代控制理论
    - 参考教材：裴润，宋申民主编，自动控制原理（下册），哈尔滨工业大学出版社。
    - 主要内容：基于状态空间模型的控制理论
      - 系统建模：状态空间模型
      - 系统分析：时域分析，能观能控性分析，Lyapunov 稳定性分析
      - 系统综合：状态空间综合
  - 最优控制理论
    - 参考教材：裴润，宋申民主编，自动控制原理（下册），哈尔滨工业大学出版社。
    - 主要内容：
      - 变分法
      - Pontryagin 极小值原理
      - 动态规划
  - 随机控制理论
    - 参考教材：蔡尚峰编著，随机控制理论，上海交通大学出版社。
    - 主要内容：
      - 数学基础：随机过程
      - 系统建模：随机系统数学模型
      - 系统分析：时域分析
      - 系统综合：状态估计问题-卡尔曼滤波
- 电机理论
  - 电磁场
    - 参考教材：西安交通大学冯慈璋、马西奎著，工程电磁场导论，高等教育出版社。
    - 主要内容：
      - 数学基础：矢量分析
      - 静电场，恒定电场，静磁场，时变电磁场，准稳态电磁场
  - 电机学
    - 参考教材：汤蕴璆编著，电机学（第五版），机械工业出版社。
    - 主要内容：
      - 变压器
      - 直流电机
      - 交流电机：感应电机，同步电机  
  - 电力拖动自动控制系统
    - 参考教材：阮毅，杨影，陈伯时编著，电力拖动自动控制系统-运动控制系统（第5版），机械工业出版社。
    - 主要内容：
      - 直流调速系统：转速开环系统，转速闭环系统，转速、电流双闭环系统，调速系统的数字控制
      - 基于稳态模型的交流调速系统：异步电动机调速系统，绕线转子转子变频调速系统，同步电动机变频调速系统
      - 伺服系统
  - 现代电机控制技术
    - 参考教材：王成元, 夏加宽, 孙宜标编著，现代电机控制技术（第二版），机械工业出版社。
    - 主要内容：
      - 矢量控制
      - 直接转矩控制
      - 无传感器控制
